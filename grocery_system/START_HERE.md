# 🏪 نظام إدارة البقالة - دليل البدء السريع

## 📋 نظرة عامة

نظام بسيط وفعال لإدارة مخزون البقالة والمبيعات اليومية، يعتمد على ملفات CSV التي يمكن فتحها وتعديلها مباشرة في Microsoft Excel.

## 🚀 البدء السريع

### الطريقة الأولى: استخدام Excel (الأسرع)

1. **افتح ملف `inventory.csv` في Excel**
   - يمكنك إضافة/تعديل/حذف المنتجات مباشرة
   - Excel سيحفظ التغييرات تلقائياً

2. **افتح ملف `daily_sales.csv` لتسجيل المبيعات**
   - أضف صفوف جديدة لكل عملية بيع
   - ستكون البيانات جاهزة للتحليل

3. **افتح ملف `stock_adjustments.csv` لمتابعة التعديلات**
   - يتم تسجيل جميع تعديلات المخزون تلقائياً

### الطريقة الثانية: استخدام برنامج Python

1. **شغل النظام:**
   ```bash
   # انقر نقراً مزدوجاً على ملف run_system.bat
   # أو شغل الأمر التالي:
   python grocery_manager.py
   ```

2. **اختر من القائمة:**
   - 1: عرض تقرير المخزون
   - 2: إضافة منتج جديد
   - 3: تسجيل بيع
   - 4: تحديث كمية منتج
   - 5: تقرير المبيعات اليومية
   - 6: تقرير شهري
   - 7: خروج

## 📊 ملفات النظام

### inventory.csv (ملف المخزون)
يحتوي على جميع المنتجات مع:
- رقم المنتج
- اسم المنتج
- التصنيف
- الوحدة (كيس، لتر، كرتونة، إلخ)
- سعر الشراء (سعر الدراوج)
- سعر البيع (سعر البيوع)
- الكمية الحالية
- الحد الأدنى للمخزون
- الإجمالي
- الحالة (متوفر، منخفض، نفذ)
- ملاحظات

### daily_sales.csv (ملف المبيعات)
يسجل جميع عمليات البيع:
- التاريخ
- رقم البيع
- اسم المنتج
- الكمية المباعة
- الوحدة
- سعر الوحدة
- الإجمالي
- طريقة الدفع (نقد، تحويل بنكي)
- بيانات العميل (اختياري)
- ملاحظات

### stock_adjustments.csv (تعديلات المخزون)
يسجل جميع تعديلات المخزون:
- التاريخ
- اسم المنتج
- الكمية القديمة
- الكمية الجديدة
- الفرق
- السبب

## 🎯 الاستخدام اليومي

### إضافة منتج جديد:
```python
manager.add_product(
    name="شاي",
    category="مشروبات",
    unit="كيس",
    purchase_price=1486.49,
    selling_price=2500,
    quantity=37,
    min_stock=10
)
```

### تسجيل بيع:
```python
manager.record_sale(
    product_name="شاي",
    quantity=2,
    unit="كيس",
    selling_price=2500,
    payment_method="نقد",
    customer_name="أحمد محمد",
    customer_phone="01012345678"
)
```

### تحديث الكمية:
```python
manager.update_quantity(1, 35)  # تحديث المنتج رقم 1 إلى 35 وحدة
```

## 🔧 معادلات Excel مفيدة

### حساب الإجمالي تلقائياً:
```
= الكمية * سعر الشراء
```

### تحديد الحالة تلقائياً:
```
=IF(الكمية=0,"نفذ",IF(الكمية<=الحد_الأدنى,"منخفض","متوفر"))
```

### حساب الربح:
```
= (سعر البيع - سعر الشراء) * الكمية
```

## 💡 نصائح مهمة

1. **النسخ الاحتياطي:**
   - احتفظ بنسخة احتياطية من ملفات CSV بشكل دوري
   - يمكنك نسخ المجلد بالكامل

2. **التنظيم:**
   - استخدم تصنيفات واضحة للمنتجات
   - حافظ على تسمية موحدة للوحدات

3. **المراقبة:**
   - راجع تقرير المخزون المنخفض يومياً
   - قم بطلب المنتجات المنخفضة قبل نفادها

4. **التحليل:**
   - راجع التقارير الشهرية لفهم الأداء
   - حدد المنتجات الأكثر مبيعاً

## 🛠️ استكشاف الأخطاء

### المشكلة: لا يفتح الملف في Excel
**الحل:** تأكد من أن الملف بتنسيق CSV UTF-8

### المشكلة: الأرقام تظهر كنص
**الحل:** في Excel، حدد العمود → Data → Text to Columns

### المشكلة: البرنامج لا يعمل
**الحل:** تأكد من تثبيت Python على جهازك
