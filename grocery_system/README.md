# نظام إدارة البقالة البسيط

نظام بسيط لإدارة المخزون والمبيعات يعتمد على ملفات CSV التي يمكن فتحها في Excel.

## الملفات

- `inventory.csv` - ملف المخزون (يمكن فتحه في Excel)
- `daily_sales.csv` - ملف المبيعات اليومية
- `stock_adjustments.csv` - ملف تعديلات المخزون
- `grocery_manager.py` - برنامج Python لإدارة النظام

## طريقة الاستخدام

### الطريقة 1: استخدام Excel مباشرة

1. افتح ملف `inventory.csv` في Excel
2. يمكنك:
   - إضافة منتجات جديدة
   - تعديل الأسعار والكميات
   - حذف منتجات
3. افتح ملف `daily_sales.csv` لتسجيل المبيعات
4. افتح ملف `stock_adjustments.csv` لمتابعة تعديلات المخزون

### الطريقة 2: استخدام برنامج Python

تأكد من تثبيت Python على جهازك، ثم شغل البرنامج:

```bash
python grocery_manager.py
```

ستظهر لك قائمة بالخيارات:
1. عرض تقرير المخزون
2. إضافة منتج جديد
3. تسجيل بيع
4. تحديث كمية منتج
5. تقرير المبيعات اليومية
6. تقرير شهري
7. خروج

## هيكل ملف المخزون (inventory.csv)

| العمود | الوصف |
|--------|-------|
| رقم | رقم المنتج |
| اسم المنتج | اسم المنتج بالعربية |
| التصنيف | تصنيف المنتج (مشروبات، مواد غذائية، إلخ) |
| الوحدة | وحدة القياس (كيس، لتر، كرتونة، إلخ) |
| سعر الشراء | سعر الشراء (سعر الدراوج) |
| سعر البيع | سعر البيع (سعر البيوع) |
| الكمية | الكمية الحالية في المخزون |
| الحد الأدنى | الحد الأدنى للمخزون |
| الإجمالي | الإجمالي = الكمية × سعر الشراء |
| الحالة | الحالة (متوفر، منخفض، نفذ) |
| ملاحظات | ملاحظات إضافية |

## هيكل ملف المبيعات (daily_sales.csv)

| العمود | الوصف |
|--------|-------|
| التاريخ | تاريخ البيع |
| رقم البيع | رقم فريد لكل عملية بيع |
| اسم المنتج | اسم المنتج المباع |
| الكمية | الكمية المباعة |
| الوحدة | وحدة القياس |
| سعر الوحدة | سعر البيع للوحدة |
| الإجمالي | الإجمالي = الكمية × سعر الوحدة |
| طريقة الدفع | طريقة الدفع (نقد، تحويل بنكي) |
| اسم العميل | اسم العميل (اختياري) |
| رقم الهاتف | رقم هاتف العميل (اختياري) |
| ملاحظات | ملاحظات إضافية |

## مثال على استخدام النظام

### إضافة منتج جديد:

```python
manager = GroceryManager()
manager.add_product(
    name="شاي",
    category="مشروبات",
    unit="كيس",
    purchase_price=1486.49,
    selling_price=2500,
    quantity=37,
    min_stock=10
)
```

### تسجيل بيع:

```python
manager.record_sale(
    product_name="شاي",
    quantity=2,
    unit="كيس",
    selling_price=2500,
    payment_method="نقد",
    customer_name="أحمد محمد",
    customer_phone="01012345678"
)
```

### الحصول على تقرير المخزون:

```python
report = manager.get_inventory_report()
print(f"قيمة المخزون: {report['total_value']} ج.م")
print(f"الربح المحتمل: {report['potential_profit']} ج.م")
```

## النصائح

1. احتفظ بنسخة احتياطية من ملفات CSV بشكل دوري
2. يمكنك استخدام معادلات Excel في ملف المخزون للحسابات التلقائية
3. للحسابات التلقائية في Excel:
   - الإجمالي: `=K2*G2` (الكمية × سعر الشراء)
   - الحالة: `=IF(K2=0,"نفذ",IF(K2<=H2,"منخفض","متوفر"))`
